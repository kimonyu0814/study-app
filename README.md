# 학습기록 앱

학습기록 · 정답확인 웹페이지를 담은 안드로이드 앱입니다.

- 아침 8:00 · 저녁 5:50 할 일 알림
- 홈 화면 위젯 (시험 D-day + 오늘 할 일)
- 새 버전 알림 → 눌러서 업데이트

## 폴더
- `docs/` — 웹페이지 (GitHub Pages 로 공개, 고치면 앱에 바로 반영)
  - `index.html` 학습기록, `check.html` 정답확인
- `app/` — 안드로이드 앱 코드 (고치면 GitHub Actions 가 새 APK 를 만듦)

## 설치
**Releases** → 최신 버전 → `study-app.apk` 를 휴대폰에서 내려받아 설치합니다.
